Đặt vấn đề và mục tiêu

Thực trạng

  • Ghi tồn kho bằng sổ tay hoặc Excel, dễ sai lệch
  • Khó biết size, màu, hãng nào sắp hết
  • Báo cáo doanh thu mất nhiều thời gian

Mục tiêu

  • Quản lý sản phẩm, nhập hàng, bán hàng trên một hệ thống
  • Tồn kho cập nhật tự động sau mỗi giao dịch
  • Thống kê doanh thu, lợi nhuận theo thời gian

Phạm vi

  • Một cửa hàng bán lẻ: bóng, giày, quần áo, phụ kiện
  • Ba nhóm người dùng: chủ cửa hàng, thu ngân, thủ kho

Mã SQL: bảng và trigger trừ tồn kho

-- Đầy đủ trong docs/schema.sql
CREATE TABLE SanPham (
  MaSP INT IDENTITY PRIMARY KEY, TenSP NVARCHAR(150) NOT NULL,
  MaLoai INT REFERENCES LoaiSP(MaLoai),
  MaNCC  INT REFERENCES NhaCungCap(MaNCC),
  Hang NVARCHAR(50), Size NVARCHAR(20),
  GiaNhap MONEY, GiaBan MONEY,
  SoLuongTon INT DEFAULT 0 CHECK (SoLuongTon >= 0));

CREATE TRIGGER trg_BanHang ON ChiTietHoaDon AFTER INSERT AS
  UPDATE s SET s.SoLuongTon = s.SoLuongTon - i.SoLuong
  FROM SanPham s JOIN inserted i ON s.MaSP = i.MaSP;

Ràng buộc CHECK ngăn bán vượt số lượng tồn; trigger giữ tồn kho luôn đúng.

Kiến trúc và công nghệ

Giao diện

C# Windows Forms: form đăng nhập, form chính, form bán hàng, form báo cáo.

Xử lý nghiệp vụ

Tách lớp: GUI, BLL (nghiệp vụ), DAL (truy cập dữ liệu) bằng ADO.NET.

Dữ liệu

SQL Server, truy vấn bằng tham số để tránh SQL Injection.

Báo cáo

Xuất hóa đơn, báo cáo doanh thu bằng Report Viewer hoặc Excel.
